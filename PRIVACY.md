# Privacy Policy — Expense Bot

Expense Bot is a personal expense tracking application.

## Data collected

The application may process:

- Telegram user identifiers
- Telegram display names
- Expense amounts
- Expense categories
- Expense dates

## Google Drive access

Expense Bot uses Google Drive API access only to create and update
expense archive files in the Google Drive account authorized by the user.

The application does not sell, share, or transfer Google user data
to third parties.

Google Drive data is used only for storing and updating expense archives.

## Data storage

Recent expense data may be stored in the application's database.
Older expense data is archived to the authorized user's Google Drive.

## Contact

For questions regarding this privacy policy, contact the application developer.
